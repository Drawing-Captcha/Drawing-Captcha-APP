## Reporting a Vulnerability

If you discover a security vulnerability, please report it by opening an issue in this repository.

### Instructions:
1. Navigate to the [Issues section](https://github.com/Drawing-Captcha/Drawing-Captcha-APP/issues) of this repository.  
2. Open a new issue and provide as much detail as possible about the vulnerability.  
   - Include steps to reproduce the issue, if applicable.  
   - Mention the environment or version where the issue was found.  
3. Clearly indicate in the title that it is a security issue (e.g., `[SECURITY] Vulnerability in ...`).  

### What to Expect:
- We will acknowledge your report **as quickly as possible**.  
- Once resolved, we will credit you for the discovery on the Security Advisory.  

We appreciate your assistance in keeping this project secure for everyone!
